# snap_analyze

A comprehensive, lightweight Python analysis library designed for structural, physical, and dynamical characterization of particle and molecular dynamics trajectories (e.g., generated by HOOMD-blue and stored in GSD files). It features cell-list-accelerated algorithms for efficient spatial partitioning and supports calculations in both 2D and 3D systems.

`snap_analyze` is built to work seamlessly with [snap_simulate](file:///home/tanner/snap_simulate) (which constructs and executes simulations) and [snap_workflow](file:///home/tanner/snap_workflow) (which orchestrates sweeps and job scheduling).

---

## Features

### 🧼 Network Topology & Bond Analysis (`analyze.py`)
- **Bond Splitting**: Splits a raw list of bonds into static (structural) and dynamic (transient) bond networks (`split_static_dyn_bonds`).
- **Complex & Cluster Finding**: Uses `networkx` graphs to group bonded particles into connected component complexes/molecules (`get_complexes`).
- **Intermediate Removal**: Reconnects bond networks by removing intermediate linker/solvent particles and mapping direct connections between endpoints (`remove_bond_intermediates`).

### 📦 Spatial Clustering & Shape Characterization (`cluster.py`)
- **Cluster Identification**: Groups particles into spatial clusters based on a physical cutoff distance `r_max` (`Clusters`).
- **Structural Properties**: Calculates average cluster size distributions, centers of mass, and gyration tensors for identified clusters.
- **Anisotropy Calculation**: Computes shape anisotropy and relative shape anisotropy parameters (`calc_anisotropy`) to measure cluster geometry and elongation.

### ⏱️ Trajectory & Particle Dynamics (`dynamics.py`)
- **Mean Squared Displacement (MSD)**: Computes particle MSD across overlapping timesteps to maximize statistical averaging.
- **Self-Intermediate Scattering Function ($F_s(k,t)$)**: Calculates the $F_s(k,t)$ (`Fskt`) of the system using randomized, isotropic wave-vectors to analyze structural relaxation.
- **Self van Hove Correlation Function ($G_s(r,t)$)**: Computes the 1D self van Hove correlation function to trace particle displacements over time.

### 🔍 Efficient Neighbor Search (`neighbor_list.py`)
- **Cell-List Partitioner**: Implements an $O(N)$ cell-list partitioner (`NeighborList`) for 2D/3D periodic boxes, avoiding expensive $O(N^2)$ distance evaluations.
- **Cross-Set Neighbor Finder**: Supports cross-set neighbor discovery (`MultiNeighborList`) to find interactions between two separate sets of particle positions (e.g., particles and virtual dipoles).

### ❄️ Bond-Orientational Order (`psik.py`)
- **Crystalline Order Tracking**: Calculates the local bond-orientational order parameter $\psi_k$ for each particle (`Psi_k`).
- **Hexatic/Tetratic Order**: Useful for tracking 2D crystalline order transitions (e.g., hexatic order with $k=6$, tetratic order with $k=4$).

### 📏 Radial Distribution Function (`rdf.py`)
- **Structural Correlations**: Computes the radial distribution function $g(r)$ (`RDF`) for particle systems.
- **Dimensionality Support**: Handles both 2D and 3D periodic boundary boxes, applying appropriate dimensional volume normalization.

### 🌐 Static Structure Factor (`structure_factor.py`)
- **Reciprocal Space Analysis**: Computes the static structure factor $S(\vec{k})$ in 2D/3D and the 1D isotropic structure factor $S(k)$ (`Static_Structure_Factor`).
- **FFT Acceleration**: Leverages fast Fourier transforms (FFT) of grid-discretized densities for rapid computation over large particle configurations.

### 📐 2D Voronoi Analysis (`voronoi.py`)
- **Voronoi Tessellation**: Computes custom cell-based Voronoi diagrams (`Voronoi_Analysis`) in 2D.
- **Periodic Boundary Replication**: Safely handles periodic boundary conditions by replicating border particles prior to tessellation.
- **Neighbor Network**: Identifies border cells, cell vertices, and extracts Voronoi-based neighbor lists.

## Installation

To install `snap_analyze` locally in editable mode:

```bash
git clone https://github.com/tanner/snap_analyze.git
cd snap_analyze
pip install -e .
```

### Requirements
- **Python** &ge; 3.8
- **numpy**
- **scipy**
- **networkx**
- **matplotlib**
- **gsd** (optional, required for reading GSD simulation trajectories)

## Quick Start Examples

### 1. Radial Distribution Function $g(r)$
```python
import numpy as np
from snap_analyze import RDF

# System properties
box_length = np.array([50.0, 50.0, 50.0])
bin_edges = np.arange(0.0, 15.0, 0.1)

# Initialize RDF calculator
rdf_calculator = RDF(box_length=box_length, bin_edges=bin_edges)

# Append frames from a trajectory
for positions in trajectory_frames:
    rdf_calculator.append_sample(positions)

# Compute midpoints and g(r) values
bin_mids, g_r = rdf_calculator.compute()
```

### 2. Particle Dynamics (MSD and $F_s(k,t)$)
```python
import numpy as np
from snap_analyze import dynamics

# Initialize dynamics tracker
box = np.array([40.0, 40.0, 40.0])
dyn = dynamics(box=box, kmag=1.1, min_avg_count=5)

# Record positions and images over time
for step, (positions, images) in enumerate(trajectory):
    dyn.append_timestep(timestep=step * 0.005, pos=positions, img=images)

# Compute MSD and Intermediate Scattering Function
dts_msd, msd = dyn.calc_MSD()
dts_fs, fskt = dyn.calc_Fskt()
```

### 3. Spatial Clustering & Gyration
```python
import numpy as np
from snap_analyze import Clusters

# Find spatial clusters within a cutoff of 1.2
box = np.array([30.0, 30.0, 30.0])
cluster_finder = Clusters(r_max=1.2, box_length=box)
cluster_finder.append(positions)

# Get the list of particle indices in each cluster
clusters = cluster_finder.get_last_clusters()

# Compute physical properties of the clusters
centers_of_mass = cluster_finder.calc_center_mass()
gyration_tensors = cluster_finder.calc_gyration_tensor()
shape_anisotropies = cluster_finder.calc_anisotropy()
```

### 4. Static Structure Factor $S(k)$
```python
import numpy as np
from snap_analyze import Static_Structure_Factor

# Initialize Structure Factor with cell size
box = np.array([40.0, 40.0, 40.0])
ssf = Static_Structure_Factor(cell_size=1.0, box_length=box)

for positions in trajectory_frames:
    ssf.append(positions)

# Retrieve 1D isotropic structure factor S(k)
k_values, s_k = ssf.get_1D_Sk()
```
