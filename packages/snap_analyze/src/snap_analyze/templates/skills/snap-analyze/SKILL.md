# snap-analyze Skill

`snap_analyze` provides high-performance trajectory processing and statistical mechanics analysis algorithms for simulation output generated by pySNAP and HOOMD-blue.

---

## 1. GSD Trajectory Loading & Frame Parsing

`snap_analyze` interfaces with `.gsd` trajectory files to extract particle positions, species types, box matrices, and velocities across time steps.

```python
import gsd.hoomd
import numpy as np

# Load trajectory file
traj = gsd.hoomd.open("trajectory.gsd", "r")
print(f"Total trajectory frames: {len(traj)}")

# Inspect last frame
frame = traj[-1]
positions = frame.particles.position
types = frame.particles.typeid
box = frame.configuration.box  # [Lx, Ly, Lz, xy, xz, yz]
```

---

## 2. Structural Observables & Correlation Functions

### Radial Distribution Function ($g(r)$)
Calculates pair correlation functions between particle species taking periodic boundary conditions into account.

```python
from snap_analyze.structure import compute_rdf

# Compute RDF between type 'A' (id 0) and type 'B' (id 1)
r, g_r = compute_rdf(
    frame=frame,
    type_i=0,
    type_j=1,
    r_max=5.0,
    dr=0.05
)
```

### Static Structure Factor ($S(q)$)
Computes reciprocal space density fluctuations for structural ordering analysis.

```python
from snap_analyze.structure import compute_structure_factor

q_vals, s_q = compute_structure_factor(
    positions=positions,
    box=box[:3],
    q_max=10.0
)
```

## 3. Dynamic Observables & Time Autocorrelation

### Mean Squared Displacement (MSD)
Calculates particle diffusion $\langle |\mathbf{r}(t) - \mathbf{r}(0)|^2 \rangle$ with unwrapped periodic coordinates.

```python
from snap_analyze.dynamics import compute_msd

time_lags, msd_vals = compute_msd(
    trajectory=traj,
    type_id=0  # Calculate for bead type 0
)
```

### Time Autocorrelation Functions
Computes temporal correlation decay $C(t) = \langle A(0) A(t) \rangle / \langle A(0)^2 \rangle$ for arbitrary time series observables.

```python
from snap_analyze.dynamics import compute_autocorrelation

lags, c_t = compute_autocorrelation(time_series=potential_energies)
```

## 4. Integration with `snap_workflow.Data_Manager`

`snap_analyze` scripts automatically return structured dictionary metrics that `snap_workflow` collects into `.dm` output files across entire parameter sweeps:

```python
# Standard collect.py script in a stage directory
def collect():
    import gsd.hoomd
    from snap_analyze.structure import compute_rdf

    traj = gsd.hoomd.open("trajectory.gsd", "r")
    r, g_r = compute_rdf(traj[-1], type_i=0, type_j=0)
    
    return {
        "peak_g_r": float(np.max(g_r)),
        "r_first_shell": float(r[np.argmax(g_r)])
    }
```

## Best Practices for AI Agents

1. **Unwrapped Coordinates**: When computing transport properties like MSD, ensure unwrapped particle coordinates (or particle image flags) are used to prevent jump artifacts at box boundaries.
2. **Chunked Trajectory Processing**: For very large GSD files (>10,000 frames), iterate over frame chunks or stride frames (`traj[::10]`) to optimize memory usage.
