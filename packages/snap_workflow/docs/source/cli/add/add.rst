workflow add
============

Synopsis
"""""""""

workflow add <*component*> ...

Description
""""""""""""

Starts a guided prompt to add a new <*component*> to the current workflow.

Arguments
""""""""""

<*component*>
    Can be any of the following:

    * :doc:`variable <variable>`
    * :doc:`stage <stage>`
    * :doc:`sweep <sweep>`
