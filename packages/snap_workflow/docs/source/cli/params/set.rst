workflow params set
===================

Synopsis
""""""""

.. code-block:: bash

   workflow params set [--format <format>|--json|--yaml]

Description
"""""""""""

Sets the default file format for saving parameters in this workflow and future operations.

Options
"""""""

**-f** *format*, **\--format** *format*
    File format to use (``json`` or ``yaml``).

**\--json**
    Shortcut flag to set the default format to JSON.

**\--yaml**
    Shortcut flag to set the default format to YAML.
