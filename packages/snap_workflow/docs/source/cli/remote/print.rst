workflow remote print
=====================

Synopsis
""""""""

.. code-block:: bash

   workflow remote [print] [name]

Description
"""""""""""

Displays a formatted table of all registered remotes, showing their name, host address, remote directory path, and current SSH connectivity status.
Running ``workflow remote`` without a subcommand defaults to this view.

Arguments
"""""""""

[*name*]
    Filter details to a specific remote system name.
