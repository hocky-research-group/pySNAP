workflow server
===============

Synopsis
""""""""

**workflow server** <*action*> ...

Description
""""""""""""

Manages worker coordination server start, autonomous scheduling, and compute allocation reservation routines.

Arguments
""""""""""

<*action*>
    Can be any of the following:

    * :doc:`start <start>`
    * :doc:`auto <auto>`
    * :doc:`reserve <reserve>`
