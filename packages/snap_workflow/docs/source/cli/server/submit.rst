workflow server submit
======================

Synopsis
""""""""

**workflow server submit** <*target*> ...

Description
""""""""""""

Dispatches worker environments or auto-run tasks to workstation/cluster resources.

Arguments
""""""""""

<*target*>
    Can be any of the following:

    * :doc:`worker <submit_worker>`
    * :doc:`auto <submit_auto>`
