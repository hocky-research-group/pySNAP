workflow sweep print
====================

Synopsis
""""""""

.. code-block:: bash

   workflow sweep [print] [-w <sweep>]

Description
"""""""""""

Displays registered workflow sweeps and their configured parameter values. Running ``workflow sweep`` without a subcommand defaults to this view.

Options
"""""""

**-w** *sweep_name*, **\--sweep** *sweep_name*
    Filter output to display a specific sweep name. Defaults to all registered sweeps.
